# 月のことば拾い 3D

月の海に浮かぶ、うさぎの小さな舟。落ちてくる言葉を三つ拾うと、短い詩になります。
Godot 4.6.3 の3D版です。

**ブラウザで遊ぶ: https://yo4e.github.io/moon-poem-game/**

WebGL 2.0 対応ブラウザで開いてください。音は開始ボタンを押したあとに再生されます。
画面の縦横比を保つため、縦長の画面には余白が表示されます。

## 遊ぶ
Godot 4.6 以降で project.godot を開いて F5。
または godot --path /path/to/moon-poem-game-3d

- 開始・もう一度: ボタン、Space、Enter
- 舟を動かす: W A S D / 全方向の矢印キーを押す。W / ↑で奥へ、S / ↓で手前へ
- マウス: 水面をクリック、または左ボタンでドラッグ。タッチ・ドラッグも対応
- 金色の輪が言葉の落ちる場所。細い光の線が、言葉と輪を結びます
- 一時停止・再開: Esc。クリック・Spaceでも再開
- 音: M、または右上の音ボタン
- 完成した詩: 「詩をコピー」

通常約25〜35秒で一つの詩。時間制限もゲームオーバーもありません。
言葉を取りこぼしたら、また降ってきます。
ネット接続・アカウント不要。外部通信・データ送信なし。
音声デバイスがない環境では静かに動作します。

## 3Dのしくみ
Node3D、透視投影Camera3D、CSGで厚みを付けた舟、立体のうさぎ、動く水面メッシュ、
立体の島・月・星、OmniLight3Dのランタンを使用。言葉は3D空間のLabel3Dです。
画面を読みやすくするメニュー・説明文だけは2DのCanvasLayerに配置しています。

## テスト
`godot --headless --path . -- --self-test`
実体の3Dノード、開始、三段階のキャッチ、詩の完成、リプレイ初期化、一時停止、
X/Z距離による衝突判定、同じXでも違う奥行きなら拾わないこと、
手前と奥のポインター座標変換、W/Sによる奥行き移動、取りこぼし後の再出現を検証します。
クラウドGUIでもプレイ、文字表示、移動、一時停止、再開、再プレイを確認。
タッチ操作コードは実装済みですが、タッチ実機のテストはしていません。

## Web公開・開発

`main` への push で GitHub Actions が公式 Godot 4.6.3 と公式テンプレートを取得し、
インポート、自動テスト、Web出力、GitHub Pages 公開を行います。
Compatibility レンダラー、単一スレッド出力を使用し、特別な分離ヘッダーは不要です。
ローカルではテンプレートを導入し、`mkdir -p build/web` のあと
`godot --headless --path . --export-release Web build/web/index.html` を実行します。
出力ファイルは名前を変えず、HTTPサーバーで配信してください。

コードの公開ライセンスは未指定です。フォントの OFL は上記ファイルを参照してください。
タッチ実機、とくに iPhone Safari の動作は未確認です。
ブラウザによって詩のコピーが許可されない場合がありますが、ゲームは続けられます。
